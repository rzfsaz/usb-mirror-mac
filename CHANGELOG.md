# Changelog

## 1.2.0

- Added Bahasa Indonesia, English, Japanese, and Simplified Chinese, including controls, connection messages, orientation labels, and the OBS guide.
- Added System, Light, and Dark themes with saved preferences.
- Language and appearance changes apply without restarting capture.
- Added a custom application icon and theme-specific in-app logos.
- Localized macOS permission descriptions for all four supported languages.
- Included a downloadable Apple Silicon app build in GitHub Releases.

## 1.1

- Added automatic portrait/landscape window sizing, manual 90° rotation, and reset.
- Redesigned native controls with a compact layout and an on-demand OBS guide.
- Added geometry checks for aspect ratio preservation and desktop bounds.

## 1.0

- Initial USB iPhone mirroring and audio playback with a clean capture window for OBS.
- Automatic device discovery, first-frame status, and muted audio on startup.
